# ⚡ Electronics E-Commerce Store

A modern and responsive electronics e-commerce web application built with **React**, **Vite**, and **Tailwind CSS**. The project provides a clean shopping experience with a focus on performance, responsive design, and reusable UI components.

## 🚀 Features

* 🛒 Product catalog with responsive grid layout
* 🔍 Product details page
* ❤️ Wishlist functionality
* 🛍️ Shopping cart
* 📱 Fully responsive design
* ⚡ Fast development powered by Vite
* 🎨 Modern UI built with Tailwind CSS
* 🖼️ Product image gallery
* 🔎 Image zoom functionality
* 📂 Product categories
* 💰 Price display and discounts
* ✨ Smooth UI animations
* ♻️ Reusable React components
* 🌙 Clean and intuitive user interface

## 🛠️ Tech Stack

* **React**
* **Vite**
* **Tailwind CSS**
* **JavaScript (ES6+)**
* **React Router**
* **Context API / State Management**
* **GSAP**
* **Framer Motion**
* **Embla Carousel**

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/electronics-ecommerce.git
```

Navigate to the project folder:

```bash
cd electronics-ecommerce
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
